Verification:
SVG exported with Inkscape. PNGs contain RGBA transparency; the negative-space channels are transparent. ICO inspected and contains all seven intended sizes. Small-size review uses actual source PNGs, not a scaled-up marketing mockup. At 16px fine corners soften due to antialiasing, but central voice channel and two lateral breaks remain distinguishable; use the supplied high-contrast monochrome variants for system tray UI. Teal on a dark background is not recommended.

This package contains artwork only. No EXE, repository, PC8, installer or release was changed. The receiving implementation owner should test Windows taskbar/tray rendering and DPI behavior in the actual app before release.
