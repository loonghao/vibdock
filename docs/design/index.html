硬件直发快捷键

把组合键或单个按键直接写进按键固件，适合 Ctrl + Win 这类 VibDock 无法注册为全局热键的组合，也支持 Enter、Escape 这类单键。写入后由按键自己发出该组合键，不经过目标应用判断；服务只负责写入和读回验证。首次运行的默认布局就是在这里生成的，可随时改写或清除。
