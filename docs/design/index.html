应用快捷键

识别正在运行且有窗口的应用（即使它没有播放声音），为它保存一个触发键和一条发送给该应用的快捷键。只有该应用位于前台时才会发送；发送成功不代表应用已经执行。

新增应用快捷键

两条快捷键都必须包含至少一个修饰键。触发键由 VibDock 注册；默认只在该应用位于前台时发送。后台输入法等没有前台窗口的工具需要勾选“发送到当前前台应用”，此时只确认应用正在运行，快捷键会注入到当前前台应用。发送成功不代表应用已经执行。
